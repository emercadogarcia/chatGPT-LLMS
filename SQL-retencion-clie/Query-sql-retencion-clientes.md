#  SQL PARA RETENCION DE CLIENTES
En este mini-proyecto desarrollé una solución en PostgreSQL usando stored procedures y triggers para detectar automáticamente clientes en riesgo de abandono.

📌 Contexto:
 Una empresa de retail necesita identificar clientes que han estado inactivos durante más de 60 días y activar una acción tan pronto como vuelven a comprar. Esta reactivación tardía es una señal clara de posible abandono, y una oportunidad crítica para intervenir.
