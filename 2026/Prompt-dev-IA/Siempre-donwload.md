Agregar esta sección literalmente en tus prompts:

---

## FORMATO DE ENTREGA OBLIGATORIO

La respuesta NO debe mostrarse directamente en el chat.

La salida debe generarse SIEMPRE como archivo descargable.

Formato permitido:

- `.md`
- `.txt`
- `.json`
- `.yaml`
- `.docx` (solo si se solicita explícitamente)

Reglas obligatorias:

- Generar archivo completo y validado
- Entregar enlace de descarga directo
- NO renderizar el contenido completo en el chat
- Validar integridad estructural antes de exportar
- Validar markdown antes de guardar
- Verificar:
  - bloques cerrados
  - tablas válidas
  - listas correctas
  - jerarquía consistente
  - ausencia de markdown roto
- Si existen ejemplos peligrosos:
  - convertirlos a texto indentado
  - evitar nested markdown
- El archivo debe quedar production-ready

Formato esperado de respuesta:

Archivo generado correctamente.
